# Kingdom Guards Assistant — стартовый Android-проект

Проект рассчитан на Android 9+ и собирает тестовый APK.

## Что уже реализовано
- экран добавления целей: альянс, башня, сторона;
- локальное хранение настроек;
- проверка допустимых интервалов и лимитов;
- foreground service с постоянным уведомлением;
- тестовый планировщик, который записывает шаги в Android Logcat;
- остановка тестового сценария после лимита.

## Важно: это пока не автокликер
Эта версия — **dry-run прототип**. Она не взаимодействует с Kingdom Guards, не нажимает игровые кнопки и не отправляет атаки. Сборка APK сама по себе не добавит эти функции. Работа при выключенном экране также не гарантируется Android: Doze и прошивка устройства могут приостанавливать задачи.

## Как получить APK без установки Android Studio
Для сборки используется GitHub Actions.

1. На GitHub создайте новый репозиторий, например `KingdomGuardsAssistant`.
2. На компьютере распакуйте этот архив. Важно загрузить **содержимое папки `KingdomGuardsAssistant`**, а не сам ZIP.
3. Загрузите в репозиторий все файлы и папки проекта, включая скрытую папку `.github/workflows/build-apk.yml`. Удобнее делать это в браузере на компьютере через **Add file → Upload files**; если скрытая папка не попала в загрузку, workflow не появится.
4. После загрузки откройте вкладку **Actions** в репозитории.
5. Выберите **Build Android APK** и нажмите **Run workflow**. Если пункта нет, проверьте, что файл `.github/workflows/build-apk.yml` присутствует в репозитории.
6. Дождитесь зелёной отметки успешного завершения. Откройте запуск workflow и внизу страницы скачайте артефакт `kingdom-guards-assistant-debug-apk`.
7. Распакуйте скачанный артефакт ZIP: внутри будет `app-debug.apk`. Передайте APK на Android-устройство и откройте его для установки. Если Android спросит разрешение на установку из этого источника, разрешите его для браузера или файлового менеджера, которым открываете APK.

GitHub может попросить войти в аккаунт. APK будет тестовой debug-сборкой, не публикацией в Play Store.
